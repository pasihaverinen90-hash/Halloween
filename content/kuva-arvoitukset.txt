# KUVA-ARVOITUKSET
#
# Turnauksessa pelataan tasan 11 arvoitusta tässä järjestyksessä. Freeplayssä
# pelataan lisäksi ne, joissa on rivi "vain: freeplay". Jokainen arvoitus on
# oma korttinsa, ja korttien välissä on yksi tyhjä rivi.
#
# tyyppi:   avoin (pelaaja kirjoittaa vastauksen) tai monivalinta (neljä
#           vaihtoehtoa, vastata saa kerran)
# kuva:     kuvatiedoston nimi kansiossa public/assets, esimerkiksi arvoitus-kuu.png.
#           Kuvan perään voi lisätä lyhyen tekstin plusmerkillä: arvoitus-hirvi.png + Ö
# emojit:   emojit kuvan sijaan (arvoituksessa on joko kuva tai emojit)
# kysymys:  näkyy arvoituksen yläpuolella. Siihen voi kirjoittaa myös vihjeen.
# vastaus:  oikea vastaus. Avoimeen arvoitukseen voi antaa useita hyväksyttyjä
#           vastauksia puolipisteillä erotettuina: Psyko; Psycho
# väärät:   vain monivalinnassa: kolme väärää vaihtoehtoa puolipisteillä erotettuina
# vain:     "vain: freeplay", jos arvoitus on vain freeplayssä eikä turnauksessa
#
# Isoilla ja pienillä kirjaimilla, välilyönneillä, väliviivoilla ja välimerkeillä
# ei ole väliä avoimen arvoituksen vastauksessa.
