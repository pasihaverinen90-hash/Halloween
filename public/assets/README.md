# Omat kuvat

Tähän kansioon lisätyt kuvat korvaavat pelin koodilla piirretyt kuvat.

1. Katso tiedostosta [`ASSETS.md`](../../ASSETS.md), mitä kuvia peli käyttää ja millä nimellä.
2. Valitse tässä kansiossa **Add file → Upload files**, raahaa kuva sivulle ja paina **Commit changes**.
3. Peli päivittyy muutamassa minuutissa.

Tiedoston nimen pitää olla täsmälleen sama kuin luettelossa, esimerkiksi `hirsipuu-luuranko-1.png`. Myös .jpg- ja .webp-tiedostot käyvät.

Kuvan voi poistaa avaamalla sen täällä ja valitsemalla roskakorin kuvan (**Delete file**). Silloin peli käyttää taas koodilla piirrettyä kuvaa.
